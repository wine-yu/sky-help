## 一、游戏核心机制深度拆解

### 1.1 货币与爱心系统（含锻造数据）
- **普通蜡烛（白蜡烛）**：由烛光凝聚而成。游戏中烛光分为大蜡烛堆、小蜡烛堆、黑暗植物、以及各类烛火源（如遇境石像、圣岛间歇泉）。每根蜡烛需要 **120 点烛光** 锻造。每日无加成的情况下，自然烛光产出上限大约相当于 **20根蜡烛**（约2400点），达到上限后烛火变灰，收集效率极低。跑完全图所有固定烛火加上大蜡烛堆，约可获得15-18根，剩余可通过挂机或季蜡转换。
- **爱心**：常驻主要获取方式如下：
  - 与先祖兑换：3根白蜡烛 = 1颗爱心，每位先祖可兑换3-5颗爱心不等。
  - 好友互心：花费3根白蜡烛送心，对方确认即得1颗爱心。
  - 心火：每位好友每天可点亮1次星盘心火，每次点亮获得1点心火，累积 **60点心火** 自动合成1颗爱心（即60位好友每天互火可得1颗爱心，若有20位好友则需3天）。
  - 常驻任务奖励：星光沙漠玫瑰任务、大树屋任务每个阶段均奖励爱心。
- **升华蜡烛（红蜡烛）**：仅通过伊甸献祭获得。在伊甸用光翼点亮石像，每点亮 **4个石像** 获得1根升华蜡烛。每周最多获得 **15.75根**，需要点亮63个石像。用于解锁先祖升华节点（获得永久光翼）和好友高阶社交动作。
- **季节蜡烛**：限时存在，常驻攻略不涉及。

### 1.2 光之翼与斗篷等级（含升级对照表）
- **光之翼（光翼/小金人）**：全图常驻可拾取的光翼数量为 **65个**（含试炼、圣岛、方舟、藏宝岛礁、星光沙漠等）。暴风眼路上另有10个可拾取光翼，但不计入永久翼总数，仅用于补充能量。
- **永久光翼**：通过升华蜡烛解锁先祖节点获得，在献祭后重生之路星盘领取。每解锁一个先祖的升华节点，可得到一个永久翼。全部常驻先祖（37位）的升华节点全部解锁，可获得 **37个永久翼**，加上部分地图先祖有多个升华节点或随版本追加，总数可达 **40+**。
- **斗篷等级与所需光翼总数对照**：
  - 1翼：1
  - 2翼：2
  - 3翼：4
  - 4翼：6
  - 5翼：10
  - 6翼：16
  - 7翼：24
  - 8翼：35
  - 9翼：50
  - 10翼：75
  - 11翼：100
  - 12翼：130（需升华全毕业及复刻追加，常驻玩家正常可达11翼）

### 1.3 社交与好友树全部节点价格
解锁好友树需要白蜡烛和红蜡烛，以下是常驻节点完全列表及消耗：
- 牵手：免费
- 拥抱：2白蜡
- 交谈（聊天）：3白蜡
- 传送：2红蜡
- 背背：6白蜡
- 击掌：3白蜡
- 熊抱：3红蜡
- 玩闹（打闹互动）：5白蜡
- 跳舞：5白蜡
- 额头触碰：5白蜡
- 举手击掌：2红蜡
- 秘密交流（拳头碰碰）：2红蜡
- 友谊拥抱（更亲密）：5红蜡
所有节点必须按顺序由上到下解锁，不可跳过。

### 1.4 每日任务与全冥想点具体位置
每日任务凌晨0点刷新，共有以下几种类型及其最佳完成方式：
1. **向一位朋友做动作**：在遇境星盘找一位在线好友，对着他使用任意动作即可。
2. **点亮20个烛光**：跑图过程中自然完成，或去烛火多的云野圣岛、霞谷赛道。
3. **拯救一只遥鲲**：前往雨林水母图或隐藏图，找到被黑暗植物困住的遥鲲，烧掉周围所有黑暗植物即可释放。
4. **重温先祖记忆**：每日指定一位先祖，需前往对应地图，在固定位置点燃先祖石像并跟随光芒走完回忆。位置即为各常驻先祖所在处。
5. **在指定地点冥想**：前往以下固定冥想点，打坐并回答问题。冥想点分布：
   - 晨岛：神殿前台阶中央。
   - 云野：三塔图（右侧浮岛图）山顶中央石台；八人门山顶石台旁。
   - 雨林：水母图第一座石桥中央；大树屋隐藏图树屋内。
   - 霞谷：竞技场中央冰面；圆梦村温泉旁石台。
   - 暮土：四龙图中央最高骨架上；战场图右侧废墟墙壁前。
   - 禁阁：一楼双人门旁右侧；顶楼平台中央。
6. **与陌生人同坐长凳**：前往云野八人门山顶长凳、暮土大厅正中央长凳、禁阁一楼四人门旁长凳等，等待任意玩家坐下后加入。
7. **掀翻5只螃蟹**：去雨林螃蟹洞或暮土四龙图，站在螃蟹群中长按角色大叫可一次掀翻多只。

### 1.5 遇境与常驻功能建筑
- **遇境**：家园地图，星盘可管理好友和先祖。衣柜更换服饰、乐器、道具。
- **常驻魔法工坊**：遇境右侧停靠的小船，可用蜡烛购买体型重塑、烟花、光能药剂等基础魔法。
- **遗忘方舟魔法商店**：完成方舟任务后永久解锁，提供更丰富的魔法（后详）。
- **音乐商店**：位于霞谷圆梦村，是常驻乐器兑换点。

## 二、全地图常驻光翼 · 超精确拾取指南

### 2.1 晨岛（含预言山谷）
**光翼总数：7 个**
- **路线**：从遇境进入晨岛，直接向前走。
1. **初始山洞左侧高台**：进入第一个山洞，立即看左边，有一个半圆形小高台，飞上去获取。
2. **沙丘右侧高台**：出山洞后，一直往右前方沙丘走，需要先在山洞出口右侧收集“招手先祖”打开石门，登上石门上方的高台，光翼在石头顶上。
3. **预言山谷入口洞外小山**：从晨岛神殿右侧云洞进入预言山谷，在还没进入山洞的过渡区，面向入口，往右侧看有一块独立凸起的石头，飞上去获得。
4. **水试炼终点**：通关水试炼后，在终点神坛自动获得。
5. **土试炼终点**：通关土试炼后终点获得。
6. **风试炼终点**：通关风试炼后终点获得。
7. **火试炼终点**：通关火试炼后终点获得。

### 2.2 云野（含圣岛）
**光翼总数：13 个**
- **进入方式**：晨岛神殿最深处打坐进入。
1. **平原左侧石柱顶部**：从云野初始山洞飞出，落在蝴蝶平原，往左走，最左边有一根特别高的石柱，飞到柱子顶端。
2. **右侧双人门洞内**：平原右下角有一处山丘，上面有个需要两人做蝴蝶动作打开的石门，进去后洞内石台上。
3. **左侧隐藏图入口浮空石**：在平原往左侧隐藏图入口飞，还没进入图，回头看向入口上方，有一块大浮石。
4. **左侧隐藏图最高浮岛**：进入图后一直往里飞，到达最深处环绕中心浮岛的阶梯状浮岛，最高那一座草丛后面。
5. **三塔图中间塔尖**：从平原右侧进入三塔图，三座浮塔最中间那座，直接飞上塔尖。
6. **八人门山顶石柱后**：三塔图尽头需要八人同时开启开关，进入山顶后，在一片浮空碎石的右后方石头后面。
7. **神殿后方云层浮石**：从云野神殿出来，不进雨林，转身向后方高处云层飞，有一块大浮石，上面有光翼。
8. **圣岛瀑布下水池岩壁**：从三塔图入口右侧云洞飞入圣岛，往瀑布方向飞，瀑布下方小水潭右侧山壁上。
9. **圣岛螃蟹洞内**：从主岛沙滩向左侧山体走，进入满是螃蟹的洞穴，最深处角落。
10. **圣岛最高峰山体内**：圣岛最高山峰正面有一道裂缝，飞进去内部石台上。
11. **圣岛浮岛最高处**：主岛旁边悬空浮岛，飞到最顶端。
12. **圣岛右侧海沟洞窟**：潜入圣岛右侧海面，往下游进洞窟，在岸上。
13. **圣岛间歇泉附近礁石**：中心间歇泉旁一块露出海面的礁石顶端。

### 2.3 雨林
**光翼总数：11 个**
1. **一图门后横树干上**：通过第一道需要点燃的门，右侧有一棵横倒的粗树干，跳上去走几步即可看到。
2. **二图右侧双人树洞**：第二图开始下雨，往右走到尽头，一棵中空大树干，两人进去烧掉黑暗植物，光翼在中间石台。
3. **二图左侧高枯树顶**：第二图左侧有一棵特别高的白色枯树，飞到树冠平台上。
4. **水母图入口管道上方**：从第二图进入水母图的横倒树干管道上方，可飞上去。
5. **水母图桥下洞窟**：水母图第一座石桥正下方有个洞口，游进去在石台上。
6. **水母图最高大骨架树顶**：水母图最深处巨大骨架树，绕到后面飞到最顶层。
7. **神殿前最终图右侧山壁平台**：即将进入神殿的最后一张图，右侧山壁中间有一处伸出的平台。
8. **隐藏图大树屋方向洞内**：从第三图右侧大树屋通道进入，第一个山洞内石台。
9. **隐藏图高处树冠**：大树屋隐藏图继续深入，最高一棵大树的树冠里。
10. **神殿内左侧柱子后**：进入雨林神殿，左边靠墙第一根大柱子后方。
11. **隐藏图树屋顶层**：完成所有大树屋任务后，可直通树屋顶层，光翼在顶层平台。

### 2.4 霞谷（含圆梦村）
**光翼总数：12 个**
1. **冰湖左侧浮石**：进入霞谷后直走，冰湖左边缘有一块浮在空中的石头。
2. **冰湖右侧双人山洞**：冰湖右侧山壁有一个双人门，进入后洞穴最深处。
3. **飞行赛道入口城墙上**：进入飞行赛道之前，城门上方平台。
4. **飞行赛道左侧平台**：飞行赛道中途，左侧有一方形平台，光翼在上。
5. **滑行赛道起点桥下**：滑行赛道出发点的桥底。
6. **滑行赛道中间右侧冰窟**：滑到快结束时右侧山壁有个窟窿，进去取得。
7. **竞技场最高看台**：到达终点竞技场，两侧看台最高层背后。
8. **圆梦村入口右侧房顶**：坐船到圆梦村，右边第一排房子屋顶。
9. **圆梦村温泉山洞内**：从村中心滑入温泉区，山洞内部角落。
10. **圆梦村最高处船旁**：村尽头山崖上停泊的船体旁边。
11. **神殿后方云层浮石**：出霞谷神殿后，向后上方云里飞，漂浮石上。
12. **圆梦村山顶雪人后**：圆梦村最高山顶，可通过背背飞到达，雪人身后。

### 2.5 暮土（含遗忘方舟/藏宝岛礁）
**光翼总数：12 个**

## 五、暴风眼与伊甸超详细行动手册

### 5.1 暴风眼步行路线（附掩体坐标）
- **一阶段**：进入后贴右侧山壁走。第一处风区灯柱后躲，第二处右边凹陷石头后躲，快到管道时左侧石头下躲。进管道后直走，注意飞石。
- **冥龙区**：出管道后看到冥龙，等它向左巡逻时，立刻贴左侧山壁快速冲到管道入口。如果被锁定，可退到管道内卡掉仇恨。
- **二阶段**：间歇狂风，利用大石块遮挡。推荐路线：进门直走第一块大石，等风停，冲到右边第二块石，再冲到左边墙下的石块，最后直达大门。

### 5.2 直飞暴风眼终极教程
1. 进入暴风眼后，走几步到达开阔地，不要贴山。
2. 转向右侧天空，起飞并持续向右上方上升，用云恢复能量。
3. 上升到足够高度后，会看到远处风暴墙和门，保持飞行朝向门上方那块三角缺口。
4. 接触风暴墙时，持续点击上升，可蹭墙升到上方，直接落在大门右侧台阶上。需多练习几次。

### 5.3 伊甸献祭全石像分布与安全点
- **第一部分（共30个石像）**：入口直到第一个大拐角。分布在线性道路上。安全点：入口左侧石柱后、第一个小石碑后、大管道旁。点石像建议从里往外点，利用已点石像避风。
- **第二部分（共33个石像）**：拐角后直到长廊终点。红石雨几乎不停，需趁红石间歇或利用石灯雕像遮挡。最后一个石像在终点大门前。

### 5.4 重生之路与永久翼领取
- 献祭结束后飞过星道，触碰光之生物获得烛火。到达终点后出现星盘，手动点击所有解锁过升华节点的先祖图标，领取永久光翼，切勿跳过动画。全部领完再走过大门回到遇境。

## 六、高级技巧与底层机制大合集

### 6.1 飞行技巧与能量管理
- **垂直飞**：飞行模式连续点上升，可以直上直下。
- **螺旋飞**：牵手旋转+上升，用于突破高度限制。
- **空中急停**：快速点击下降。
- **能量细节**：浅白云充能极快，深灰厚云极慢。大叫可为周围所有人回能。光能药剂瞬满。

### 6.2 遁地、穿模与单人开门
- **标准遁地**：矮人面具+警惕站姿，在大于30度的斜坡，按住角色脚部向下拉至陷入，松手。
- **常用遁地点**：
  - 云野八人门：山顶斜坡遁入，直接进入八人门内部。
  - 暮土方舟船体：船头斜坡遁入二层。
  - 禁阁办公室：入口左侧墙壁斜坡遁入。
  - 雨林神殿：门外右侧斜坡遁入。
- **单人突破双人门**：使用椅子背贴门，坐下后起身被挤入门后；或者用遁地从门下或侧面钻入。

### 6.3 防冥龙与所有免伤手段
- **卡遇境**：被锁定时点右上角设置，停在遇境确认界面，等红光消失后取消，全程无敌。
- **磕头/装死**：连续做倒地动作，概率丢失锁定。
- **后台大法**：锁定后切后台3秒，回来大概率锁定消失。
- **侧身滑步**：被锁定红光时，连续左右侧移，有时可以脱离锁定框。

### 6.4 炸花机制与24分钟极限跑图路线
- **炸花机制**：服务器检测某区域黑暗植物超过约30秒未被点燃，会自动净化。跑图时可利用等待炸花。
- **极限路线**：遇境→晨岛(遁地拿翼)→云野(三塔遁地八人门)→圣岛(间歇泉)→雨林(大树屋捷径直通隐藏图)→霞谷(圆梦村拿翼)→暮土(遁方舟)→禁阁(椅子穿墙直上顶楼)。使用背背飞和遁地可在24分钟内跑完全部大蜡烛和光翼。

### 6.5 背背飞与螺旋飞的进阶地图应用
- **速通火试炼**：双人背背飞从起点直接升空，对准终点方向，可直达祭坛。
- **上禁阁顶楼**：一楼使用背背飞可直达四楼或顶楼。
- **霞谷千鸟城**：从霞谷神殿后方使用螺旋飞，可冲到极高天空看到隐藏的千鸟城。

### 6.6 弹射起步与快速转场点
- 云野平原出口斜坡、霞谷冰湖边缘、暮土第一图斜坡，站在边缘快速上滑飞行+上升可弹射飞出极远，用于快速转场。

### 6.7 椅子、秋千及道具瞬移/穿墙
- 椅子紧贴墙，坐下起身挤入墙后。可用于禁阁四人门、办公室墙壁等。
- 在空中放椅子可当临时平台。

### 6.8 串线机制的高阶利用
- 遇境等待法：在某个区域想换服务器，点回遇境等几秒返回，大概率换房。
- 防串线：跑图时牵手保持贴近，避免过图时分开。

### 6.9 献祭与重生的特殊技巧
- 半献祭：只点完第一部分30个石像后不动，等光翼掉光，同样获得红蜡烛。
- 重生速升：跟随光鸟时持续向左上切气流，可快速收集烛火。

### 6.10 好友互动效率优化
- 星盘一键互火：点好友名字右侧蜡烛图标。
- 互心小号：多号跑图攒蜡烛互心，最快积累爱心途径。

### 6.11 每日任务瞬间完成法
- 与陌生人同坐：去云野八人门或暮土大厅，通常有人挂机。
- 掀翻螃蟹：雨林螃蟹洞大叫一次完成。
- 拯救遥鲲：水母图中间那个固定点。
- 重温先祖：提前记住各先祖位置，直接飞去。

### 6.12 矮人面具与站姿的实际应用
- 矮人面具可钻过一些低矮洞穴，如雨林小山洞。
- 警惕站姿+矮人面具是遁地标配。叉腰站姿可增加横向体积，卡入某些奇怪角落。

### 6.13 常驻乐器乐理与快速上手
- 乐器音阶：15键对应C大调自然音阶。从左到右依次为C4(Do)开始。
- 练习建议：在音乐商店免费试用所有乐器，背下键位与音高关系。

### 6.14 地图捷径与单人突破所有双人门
- 云野双人门：椅子穿墙或遁地进入。
- 雨林双人树洞：遁地进入。
- 禁阁二楼四人门：椅子挤压进入，或遁地穿入。
- 所有双人/四人门均可通过放置椅子背对门坐下起身或遁地解决。
